## 输出格式

**脚本本体通过 `write` 写入任务参数给出的候选脚本路径**，不要在最终回复中回显完整脚本。写入的脚本必须是一份可直接运行的 Playwright TypeScript 文件，以 `import` 语句开始，不含 JSON 包装、解释性前言或 Markdown 代码围栏，并符合以下结构：

```ts
import { test, expect } from '@playwright/test'

test('<与 test_case.title 一致>', async ({ page }) => {
  // 按启用步骤顺序实现
})
```

> 若同时需要视觉回归核对（见 [视觉回归核对](#视觉回归核对)），脚本开头还需要**内联**
> 该节给出的两个辅助函数——它们必须写在脚本文件内，**不得**抽取成外部模块或额外导入，
> 否则脚本无法脱离本平台运行。
